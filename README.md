# Game Developer Portfolio

A modern, high-performance portfolio website built with Next.js, React, and Tailwind CSS to showcase games, playable WebGL builds, gameplay clips, and technical projects.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **UI Library**: [React](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Package Manager**: [pnpm](https://pnpm.io/)
- **Deployment**: [Vercel](https://vercel.com/)

## Getting Started

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## Building for Production

```bash
pnpm build
```
